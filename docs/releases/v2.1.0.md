# SuiteCRM Expert Skill 2.1.0

Independent SuiteCRM 8 guidance for administration, development, integrations, troubleshooting, and operations.

## Changes

- A structured catalog for confirmed issues, without invented incident entries.
- A review register recording evidence, limitations, and update triggers for authored procedures.
- Conditional environment checks for uploads/PHP, databases, Composer, and deployments with multiple replicas.
- A behavior evaluation rubric and 12 current tasks for the 2.x scope.
- English onboarding, installation and usage guides, contribution templates, and CI/release workflows for community distribution.

## Downloads

- `suitecrm-expert-skill-openai.zip`: instructions and references, suitable for Codex local skills.
- `suitecrm-expert-skill-opencode.zip`: the same content plus optional Node.js search and inspection tools.
- `manifest.json`: archive SHA-256 checksums and file hashes.

Install one variant per environment. See the repository's installation guide.

## Validation and limitations

Before publishing this draft, link the completed release workflow run and state its actual results. Local results are recorded in `docs/PUBLICATION_CHECKS.md`; historical results are in `VALIDATION.md`.

The corpus contains 226 pinned SuiteDocs documents, including 22 legacy references tied to SuiteCRM 8 evidence. Package and retrieval checks do not establish model answer quality, hosted import acceptance, or successful live CRM operations. Standalone SuiteCRM 7 is outside scope.

# Security policy

Security fixes target the latest published release. Older releases do not have a guaranteed backport policy.

## Report a vulnerability

Use the repository's **Security → Report a vulnerability** feature if private vulnerability reporting is enabled. Include the affected version, a minimal synthetic reproduction, impact, and suggested mitigation. Do not include live credentials or customer data.

If private reporting is unavailable, open an issue requesting a private security contact without disclosing exploit details. A maintainer will arrange a private channel. This community project does not promise a fixed response time.

## Scope

Report unsafe archive handling, unintended file access, data disclosure, or dangerous project instructions here. Vulnerabilities in SuiteCRM itself should be reported to the upstream project through its own reporting channel.

The skill does not grant permissions or connect to CRM by itself. Local tools and generated recommendations still operate within the host's permissions and need release-specific review.
